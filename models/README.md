# Machine Learning Model Artifacts

This directory stores serialized models, vectorizers, and evaluation reports generated by the training pipeline.

## Stored Artifacts
- **`best_model.joblib`**: The optimal classifier selected from cross-validation and test set evaluation (Logistic Regression / Calibrated SVM).
- **`vectorizer.joblib`**: The fitted TF-IDF vectorizer trained strictly on the training partition.
- **`all_models.joblib`**: Serialized bundle of all 4 trained algorithms (MultinomialNB, LogisticRegression, RandomForest, Calibrated LinearSVC).
- **`evaluation_results.json`**: Comprehensive test metrics, cross-validation scores, confusion matrices, ROC curves, PR curves, and timing benchmarks across all models.

## Usage
These models are loaded at runtime by `src/predict.py` and the Streamlit application for fast inference without re-training.
