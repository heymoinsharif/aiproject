Frequently Asked Viva Defense Q&A
Why did you calibrate the Support Vector Machine?

Standard Linear SVM outputs uncalibrated signed hyperplane distances (decision_function). Wrapping it with CalibratedClassifierCV using Platt sigmoid scaling produces calibrated probabilities that accurately reflect threat confidence across our 3-tier thresholds.

How did you prevent data leakage during training?

We performed an 80/20 stratified split before any vectorization occurred. The TF-IDF vectorizer (5,000 unigrams & bigrams) was fitted strictly on the 8,000 training emails; the 2,000 test emails were only transformed against the fixed vocabulary.

Why does the URL scanner run 100% offline?

Making live DNS or HTTP requests to attacker-controlled URLs can trigger unique tracking beacons (confirming an active target inbox) or expose the scanner host to drive-by payloads. Static structural heuristics inspect IP hosts, shorteners, punycode, and subdomains safely offline.

What is the Accuracy Paradox in cybersecurity?

If 99% of emails are legitimate and 1% are phishing, a dummy model predicting "Legitimate" for everything reaches 99% accuracy while letting 100% of attacks through. Recall, Precision, F1-Score, and PR Curves measure real defensive effectiveness.

Core Algorithms & Future Roadmap
  • Support Vector Machine (Calibrated Linear SVM): Optimal hyperplane margin maximization in sparse TF-IDF space (99.64% F1, 0.001 ms latency).
  • Logistic Regression (L2, Balanced): Convex cross-entropy linear classifier with direct log-odds interpretability (99.28% F1).
  • Random Forest (100 Trees): Non-linear ensemble resistant to overfitting with strong recall (98.75% F1).
  • Multinomial Naive Bayes: Ultra-fast generative probabilistic baseline (96.04% F1, 0.007 s training).
